Five words, in plain English

Everything on this page answers one question: can our AI agent safely use this app on a customer’s behalf?

Auth
How the app checks who is calling. An API key is a password for software; OAuth is the “Log in with…” screen where a user clicks Allow.
Self-serve
A developer can sign up and get keys alone, free or on a trial. The opposite is “gated”: pay, apply, or talk to sales first.
API
The documented doorway software uses to read and change data in the app. REST and GraphQL are the two common styles.
MCP
Model Context Protocol: a plug that lets an AI assistant use an app’s tools directly. A vendor MCP is one the app maker publishes.
Toolkit
The set of actions our agent can take inside an app, such as “create a contact” or “send a message”.

The agent that did the reading

A Python pipeline in this repo, run once per app, in parallel. It does not guess; it checks each claim against the live page and keeps the sentence that proves it.

  1. Step 1

    Draft from memory

    An AI model fills in all 100 rows from what it already knows. Fast, but unproven: this is pass 1.

  2. Step 2

    Fetch the docs

    Downloads each docs page. If a site blocks it or only renders with JavaScript, a headless Chrome browser opens it instead.

  3. Step 3

    Follow the trail

    Opens up to two linked pages about auth, pricing or getting started, plus the site’s llms.txt index where one exists.

  4. Step 4

    Look for proof

    Scans the text for OAuth, API keys, Basic login, GraphQL, MCP, “contact sales”, “free trial” and similar, and saves the sentence it found.

  5. Step 5

    Ask the MCP registry

    Queries the official MCP Registry for a server published under the vendor’s own name.

  6. Step 6

    Grade every claim

    Marks each claim confirmed, contradicted or no evidence. Contradictions go to a human review queue.

Where a human was needed

  • Deciding each flagged contradiction. The agent’s flags were often noise: “approval” in an OAuth paragraph is not a sales gate, and a docs site’s own search MCP is not a product MCP.
  • Improving the agent three times (v1 to v3) after seeing its mistakes; each change is commented in the code.
  • Apps whose docs were blocked, empty or missing: PitchBook, Ecwid, Paygent, iPayX, fanbasis.
  • Judging “self-serve or gated”: pricing pages rarely say it in words a script can match, so this field is the one the agent confirms least.

What still defeats it, honestly

  • About a fifth of claims have no matching sentence on the pages read. Absence of proof is not proof of absence, so those rows carry a lower confidence.
  • The access field is the weakest: words like “enterprise” appear on almost every pricing page.
  • The hand checks were done by the AI reviewer reading the saved evidence; a person should re-check the rows marked low confidence before relying on them.
